# Implemented Features

A comprehensive inventory of every feature currently built into the OSLT platform.

---

## Backend API

### Actor Management (`backend/app/routers/actors.py`)

| Endpoint | Method | Description |
|---|---|---|
| `/actors` | POST | Register a new supply-chain actor. Generates an Ed25519 keypair, derives a `did:key` DID, and returns the private key once (never persisted). |
| `/actors/{did}` | GET | Look up an actor by their DID — returns role, creation date, and blacklist status. |
| `/actors/{did}/blacklist` | POST | Revoke an actor's access by flagging them as blacklisted. |

### Digital Twin Management (`backend/app/routers/twins.py`)

| Endpoint | Method | Description |
|---|---|---|
| `/twins` | POST | Create a new Digital Twin with optional `parent_twin_id` for hierarchical BOM support. Validates actor role (RAW_MATERIAL_SUPPLIER or OEM_MANUFACTURER). |
| `/twins` | GET | List all twins with optional filtering by `product_type` and `status`. Supports pagination. |
| `/twins/{twin_id}` | GET | Retrieve full twin state including computed fields (SoH, capacity, recyclability score). |
| `/twins/{twin_id}/children` | GET | List child twins in the BOM hierarchy. |
| `/twins/{twin_id}/zkp` | POST | Generate zero-knowledge proof selective-disclosure flags (conflict-free sourcing, recycled content thresholds, EU compliance). |
| `/twins/{twin_id}/second-life` | GET | Get secondary-market reuse recommendation based on SoH, repair history, and tamper alerts. |
| `/twins/{twin_id}/recycling` | GET | Generate an automated dismantling/recycling matrix with hazard identification, target metal recovery, and disassembly sequences. |

### Event Ledger (Append-Only) (`backend/app/routers/events.py`)

| Endpoint | Method | Description |
|---|---|---|
| `/events` | POST | Append an event to the ledger. Runs a multi-step validation pipeline: actor verification, timestamp freshness, Ed25519 signature, optimistic concurrency, telemetry anomaly detection, counterfeit part detection, provenance gap detection. |
| `/events/{twin_id}` | GET | Retrieve the full event history for a twin with pagination. |
| `/events/{twin_id}/verify` | GET | Recompute and verify SHA-256 chain-hash integrity across the entire event ledger. |

### Public Digital Product Passport (`backend/app/routers/passport.py`)

| Endpoint | Method | Description |
|---|---|---|
| `/passport/{twin_id}` | GET | Public, sanitized view of a twin — strips sensitive fields (manufacturer DID, exact weights). No authentication required. |
| `/passport/{twin_id}/timeline` | GET | Public event timeline with masked DIDs, excluded SECURITY_ALERT events, compliance badges, and safety warnings. |

### Telemetry & IoT (`backend/app/routers/telemetry_ws.py`)

| Endpoint | Method | Description |
|---|---|---|
| `/telemetry/ws/{twin_id}` | WebSocket | Streams mock BMS (Battery Management System) telemetry at 1-second intervals. Auto-stops after 300 messages. |
| `/telemetry/batch` | POST | Offline-first batch sync — accepts a queue of events and processes them one-by-one with per-event error handling. |

### System (`backend/app/main.py`)

| Endpoint | Method | Description |
|---|---|---|
| `/health` | GET | Health check endpoint returning `{"status": "ok", "version": "1.0.0"}`. |
| `/docs` | GET | Swagger UI — interactive API documentation (auto-generated by FastAPI). |
| `/redoc` | GET | ReDoc — alternative API documentation view. |

## Cryptographic Services

### Ed25519 Cryptography (`backend/app/services/crypto.py`)

- **Keypair generation** — Ed25519 keypairs for all supply-chain actors
- **DID derivation** — `did:key` method identifiers from public keys
- **Canonical payload serialization** — Deterministic JSON for signature consistency
- **Signature verification** — Ed25519 signature validation on every event submission
- **Timestamp freshness checks** — Configurable replay-attack window (default 300s)

### State Engine (`backend/app/services/state_engine.py`)

- **Event replay** — Full history replay to compute current twin state
- **SoH tracking** — State of Health percentage and capacity degradation
- **Status transitions** — Automatic status updates based on SoH thresholds (ACTIVE → DEGRADED → END_OF_LIFE)
- **Recyclability scoring** — Heuristic score based on material composition and event history
- **Provenance gap detection** — Flags non-consecutive sequence numbers in event chains

### Zero-Knowledge Proof Flags (`backend/app/services/zkp.py`)

- **Selective disclosure** — Mock ZKP commitment hashes for:
  - Conflict-free sourcing verification
  - Recycled content threshold compliance
  - EU regulatory compliance flags

### Second-Life Estimation (`backend/app/services/second_life.py`)

- **Reuse pathway recommendation** — Based on SoH percentage, repair count, and tamper status
- **Market viability scoring** — Evaluates secondary-market suitability

### Recycling Matrix (`backend/app/services/recycling_matrix.py`)

- **Dismantling guide generation** — Automated material-specific disassembly sequences
- **Hazard identification** — Flags hazardous materials in the BOM
- **Target metal recovery** — Identifies high-value metals for recovery
- **Safety recommendations** — PPE and handling instructions per material type

## Data Models (`backend/app/models/`)

| Model | Table | Description |
|---|---|---|
| `Actor` | `actors` | Supply-chain participant with Ed25519 DID, role (RAW_MATERIAL_SUPPLIER, OEM_MANUFACTURER, FIELD_TECHNICIAN, RECYCLER), and blacklist flag |
| `ProductTwin` | `twins` | Digital twin with hierarchical BOM (parent_twin_id), optimistic concurrency (version_id), computed SoH/capacity/recyclability |
| `ProductEvent` | `events` | Append-only event ledger with SHA-256 chain-hash integrity, role-event permission mapping |
| `UntrustedTelemetry` | `untrusted_telemetry` | Quarantine table for anomalous or rate-exceeded IoT data |

---

## Middleware & Security

- **CORS** — Configurable allowed origins (`backend/app/main.py`)
- **Rate Limiting** — In-memory leaky-bucket algorithm (`backend/app/middleware/rate_limiter.py`)
  - Global: 600 requests/min per IP
  - Telemetry: 120 requests/min per IP
- **Ed25519 Event Signatures** — All event submissions cryptographically signed
- **Replay Attack Prevention** — Timestamp freshness window (configurable, default 300s)
- **Optimistic Concurrency** — Version-based conflict detection on twin updates

## Infrastructure

| Component | Details |
|---|---|
| **Docker Compose** | Three-service orchestration (PostgreSQL, Backend, Frontend) with health checks and dependency ordering |
| **PostgreSQL 16** | Async connections via asyncpg, connection pooling (pool_size=10, max_overflow=20), auto-create tables on startup |
| **Backend Container** | Python 3.12-slim, Uvicorn with hot-reload in dev mode |
| **Frontend Container** | Multi-stage Node 20 Alpine build, standalone Next.js output |
| **Volume Persistence** | `pgdata` named volume for database persistence |

## Event Types & Validation Pipeline

Supported event types with role-based permission checks:

| Event Type | Allowed Roles | Special Validation |
|---|---|---|
| `MATERIAL_BATCH` | RAW_MATERIAL_SUPPLIER | — |
| `BOM_ASSEMBLY` | OEM_MANUFACTURER | Parent twin must exist |
| `QUALITY_CHECK` | OEM_MANUFACTURER | — |
| `TELEMETRY_SNAPSHOT` | FIELD_TECHNICIAN | Bounds validation; quarantines anomalous readings |
| `REPAIR_PART_SWAP` | FIELD_TECHNICIAN | Counterfeit serial blacklist check |
| `DECOMMISSION` | RECYCLER | — |
| `SECURITY_ALERT` | Any | Flagged for provenance audit |
